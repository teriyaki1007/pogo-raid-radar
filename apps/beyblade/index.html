How ratings work

Scores are coach estimates for deck planning — not official Takara Tomy ratings. Meta shifts; always cross-check live tournament data before a major event.

  • Competitiveness (0–100) — Basic/UX: blade 50% + ratchet 25% + bit 25%. CX: lock 12% + main 38% + assist 15% + ratchet 17.5% + bit 17.5%, plus mass bonuses for metal Lock / Heavy Assist, plus synergy for documented partners, minus mismatch penalties. A light usage nudge (±3) applies when usagePct is present.
  • Usage % — tournament top-cut share from BEYWATCH.GG (pickRate: share of reported top-three results that included the part). Shown as “n/a” when unknown. Snapshots refresh with the data file (aim: daily when re-scraped). Not the same as win share.
  • Meta-breaking (0–100) — disruptiveness (left-spin, expand blades, CX mass stacks, unusual role stacks), capped so low-tier random trash cannot score high.
  • Value for price (0–100) — performance proxy ÷ estimated HKD mid-range cost, normalized. HK prices are ranges / estimates — not verified live listings.
  • Overall grade S–D — mostly competitiveness, lightly nudged by value.
  • CX mode — Lock Chip + Main Blade + Assist Blade + Ratchet + Bit. Display name like Emperor Blast Heavy 9-60 K. Expand blades (Glory Valkyrie, Bullet Griffon) remain Basic/UX with integrated ratchet behaviour.

See score.js and README.md for tunable weight constants.
